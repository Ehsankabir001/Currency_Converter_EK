# Currency Converter - API Integration

A responsive **Currency Converter** built using **HTML, CSS, and JavaScript**, with real-time exchange-rate data fetched from an external API.

This project is part of my **JavaScript learning journey**, where I am building practical projects to strengthen my understanding of JavaScript, DOM manipulation, asynchronous programming, and API integration.

## Live Demo

https://currencyconverterek.vercel.app/

## GitHub Repository

https://github.com/Ehsankabir001/Currency_Converter_EK

## Features

- Convert between different currencies
- Integrated a real exchange-rate API
- Dynamically loads available currencies from API data
- Uses `fetch()` to communicate with the API
- Uses `async/await` for asynchronous operations
- Dynamically creates and updates DOM elements
- Handles form submission using JavaScript
- Responsive design for different screen sizes
- Dark-themed user interface
- Custom input and select focus styling
- Removes number input spinner arrows

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Exchange Rate API
- DOM Manipulation
- Async/Await

## API Integration

The main purpose of this project was to understand how a frontend application communicates with an external API.

The basic flow of the application is:

```text
User Input
    ↓
API Request
    ↓
API Response
    ↓
Process Data
    ↓
Calculate Conversion
    ↓
Update UI
